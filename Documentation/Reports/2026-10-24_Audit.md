**Caveats.** The scan reads asset references, so it can't see assets loaded by a name built
at runtime (CharacterCustomizer may do this — keep it whole), or things only used by editor
tools. Names ending in a number (`MI_Generic_1`) are stored split by Unreal; the scan counts
every numbered variant as used when any is referenced, so it errs toward "used".

**How to remove safely (your call, in the editor):** delete a folder from the Content Browser —
the editor checks references and warns if anything still uses it — then *Fix Up Redirectors* on
the parent folder. Start with **CleanFlatIcons** and **Weapons** (nothing references them), then
the `Demo`/`Maps` folders. Deleting now shrinks the editor's scan time, the working copy and
future clones; assets already pushed to LFS stay in GitHub's LFS storage.

## 4. Repo size (`.git` = 11 GB)

| Part | Size | What it is |
|---|---|---|
| History packs | 5.0 GB | All commits before LFS (4.3 GB main pack). Stays — rewriting history isn't worth it. |
| LFS cache | 6.1 GB | `.git/lfs` — the current assets for LFS, plus stale objects from the earlier abandoned attempt. |
| Orphan packs | ~86 MB | Four `.pack` files without an index (31 Aug ×3, 30 Sep ×1) — debris git ignores ("no corresponding .idx"). |

**After the LFS push has finished** (`git status` → up to date with `origin/main`), in PowerShell
from the project folder:

```powershell
git lfs prune
```
Drops LFS objects nothing current needs (the stale ones). The current assets' copies stay —
they back your checkout.

```powershell
git fsck --connectivity-only
```
Should report no missing objects. If it does, move the four orphan packs out of `.git` (a backup
folder outside the repo, not deleted yet), then run the same `git fsck` again — still clean means
they were unused:

```powershell
New-Item -ItemType Directory -Force "$HOME\Desktop\git-orphan-packs"; Move-Item .git\objects\pack\loose-5ec9b0d72007a91fc635f319d69c3375cc3b10bd.pack, .git\objects\pack\loose-ae855f76ac67f90dfab2a110346e990c357a9864.pack, .git\objects\pack\pack-596c4ce6ab3660fdf58a02b773cc346bf3de4355.pack, .git\objects\pack\pack-b09a04c598b9ee5bee555ea2902660dfdf7ad762.pack "$HOME\Desktop\git-orphan-packs\"
```

Not recommended: `git lfs migrate import --everything` would move the 5 GB of history into LFS
too, but it rewrites every commit (force-push, re-clone everywhere) and stores every historic
asset version in LFS storage.
